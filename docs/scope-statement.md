# Phase A Scope Statement

Version 1.0 | October 10, 2026 | Parent baseline: project-charter.md

## Included

One room; one Mac controller; existing Govee strips and Vizio TV assessed individually; Mac audio evaluated as a provisional endpoint. Three predefined autumn scenes, daily schedules, opt-in media actions, automation pause/resume, basic failure feedback, installation documentation, and 30 recorded verification executions.

TV power, input selection, and ambient content playback are separate capabilities to investigate. None is promised before model-specific assessment. Integration software and transport are selected at M1; Bluetooth is not a predetermined requirement.

## Excluded

Native mobile apps, universal device discovery or compatibility, remote cloud access, AI-generated scenes, chat/SMS control, external Bluetooth speaker integration, automatic calendar-based seasonal switching, multi-room control, user accounts, billing, customer pilots, commercial launch, custom electronics, inventory purchases, and polished brand design.

The long-term seasonal vision is represented by one autumn theme in this phase. Additional seasons and holidays belong in the future backlog.

## Boundaries and completion

Use charter deliverables D1–D6 and its acceptance criteria. A simulated endpoint does not count as physical device integration. Mac audio proves Mac playback only. Unsupported TV functions require documented evidence and a conditional feasibility decision when they affect the proposed experience.

Credentials, pairing tokens, precise home network details, and device identifiers must not be committed to GitHub. Store safe configuration examples only.

## Handoff

Deliver reproducible setup, supported-function inventory, scene definitions, test results, and an evidence-based next-phase recommendation. No working application is claimed by this starter repository.
